# Third-party resources

Publication does not replace the terms attached to third-party resources.

- NASA / JPL / Goddard SVS / USGS: imagery, ephemeris references and mission-design materials. Exact sources and uses are in [resources.tsv](public/demo/resources.tsv); processing records and credits are retained in `public/assets/*provenance.json` and `public/data/`.
- ESA / Gaia / DPAC: catalogs credited by NASA's Deep Star Maps resource.
- Three.js, Lucide and npm dependencies: consult each package's license and `package-lock.json`.
- Basis Universal / KTX2: decoder notices are retained under `public/assets/basis/`.
- Fonts: source license files are retained under `tools/font-sources/`. See the resource inventory for attribution.
- Manufacturers: published specifications inform selected hardware models; proxy meshes and game credits are original approximations, not manufacturer CAD or quotations.

No commercial game assets were extracted. NASA's name and resources do not imply sponsorship, endorsement or certification. An open-source license for the original project code has not yet been designated; this notice grants no blanket license to third-party content or trademarks.
