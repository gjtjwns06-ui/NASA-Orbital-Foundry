## Save portability finding

The first short product fixture was simulated and strictly verified in Node24, then imported in Chrome157. Exact replay rejected it with BAD_CHECKPOINT. An independent same-source comparison found14 numeric leaf differences, including quaternion differences around9.2e−14, requested impulse around1.1e−12m/s, pointing around2.22e−11degrees, and minimum altitude around3.49e−10km. The failed test, original fixture and leaf comparison are retained in the independent review QA workspace.

This is a real limit of exact checkpoint portability across different JavaScript engines, not a licence to loosen a test silently. The frozen physical engine and exact validator are unchanged in this UI iteration. Subsequent short UI fixtures are generated by the actual browser engine and explicitly labeled as fixtures. The separate end-to-end acceptance uses two genuinely mouse-edited, flown browser runs. Current Chrome/Edge full-save parity was verified in version6; arbitrary past/future browser or Node portability is not claimed. A declared numerical replay compatibility policy or deterministic-math audit remains separate work.
