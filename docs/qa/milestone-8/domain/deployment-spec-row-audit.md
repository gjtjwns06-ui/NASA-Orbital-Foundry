# Original specification row audit: articulated deployment

This is a proposed wording change for the root owner to review. It does not modify the requirements matrix. The frozen domain evidence covers69 unique tests in three explicitly separate batches (65 resumed +1 recovery convergence +3 terminal-drain). Source/tests/thresholds are unchanged. Root-owned actual product interactions, renderer geometry/native recovery and integrated candidate acceptance must be cited independently.

The ASM05 proposal follows the original row's actual acceptance text: identify interference with other parts or exceeded launch-stowed dimensions. It does not require claiming a negative inter-device fixture already exists. Nevertheless that broader Stage3 plan item remains explicitly pending and must not disappear from the release boundary.

No status change is proposed for unrelated camera visibility, antenna-pointing recovery, observation scheduling, GMAT, scientific-score comparison or asset provenance rows solely from deployment-domain acceptance.
