# v14 — 실제 사진 촬영과 파일 저장

사용자 신고: 촬영해도 사진이 생기지 않고 사진을 저장할 수 없음.

## 원인과 수정

- 기존 셔터는 길게 누르는 노출만 지원했다. 짧은 클릭은 0.45초 미만 노출로 거절되어 GPU 이미지 생성까지 도달하지 않았다. 이제 짧은 클릭/Enter/Space는 0.85초 자동 노출을 요청하고, 길게 누르면 기존 수동 노출을 유지한다.
- 과학 측정 조건 실패 시에도 실제 관측기 화면은 사진으로 보존한다. 사진 저장과 과학 점수는 분리되며, 신호·기하·흔들림 기준은 변경하지 않았다.
- 최근 사진의 미리보기, 사진첩, 확대 보기와 JPEG 다운로드를 추가했다. 기존 지구 수신 기록과 개별 측정 사진에도 다운로드를 제공한다.
- 독립 사진첩은 최근 12장/총 이미지 160만 문자 이내로 저장한다. 브라우저 저장 공간 부족 시 현재 탭의 사진을 유지하고 파일 저장을 안내한다. 오래 보관할 사진은 다운로드해야 한다.
- 실제 GPU 캡처는 현재 화면 비율을 유지하고 960px 폭으로 시작한다. 기존 저장 제한을 넘으면 JPEG 품질/크기를 줄이며, 실패를 명시한다. 이전의 20만 문자 초과 이미지 무통보 폐기를 제거했다.
- 관측 저장본은 체크포인트의 12장 제한을 준수한다. 사진첩을 열면 탐사를 일시정지한다.

## 검증

- TypeScript 검사 및 production build 통과.
- 과학 운용/저장/관측기 모델 37개 + 사진첩 저장 검사 4개 통과.
- 실제 Edge 브라우저의 짧은 클릭, Enter, 실패 관측 사진, 유효 관측 사진, 다운로드, 새로고침 복원 검사 통과. JPEG를 디코딩해 렌더링된 픽셀이 존재하며 다운로드 바이트가 표시 이미지와 일치함을 확인했다. 브라우저 오류 0개.
- 1440×900 및 1280×720에서 사진, 저장, 닫기 버튼을 시각 확인했다.
- 기존 수동 노출→관측→송신→지구 수신→기록 사진 다운로드 회귀 검사도 통과했다(1분 36초, 브라우저 오류 0개). 사진 수정 관련 실제 브라우저 검사 총 2개 통과.

증거: `v14-photo-native.json`, `v14-voyage-native.json`, `v14-photo-runtime-manifest.json`, `tests/browser/artifacts/photo-capture/native-photo-result.json`.

## 배포

기존 소유자 전용 공개 범위를 유지한다. 배포 결과는 `v14-photo-deployment.json`에 기록한다. 브라우저 검증은 로컬 production build에서 수행했으며 호스팅 환경의 성능 측정은 포함하지 않는다.
